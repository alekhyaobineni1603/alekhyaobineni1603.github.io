# Alekhya Obineni — Portfolio

Recruiter-facing personal portfolio for Alekhya Obineni, B.Tech CSE at Vignan’s Foundation for Science, Technology and Research.

## Deploy with GitHub Pages
1. Create a public GitHub repository named `alekhyaobineni1603.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Open `https://alekhyaobineni1603.github.io/`.
